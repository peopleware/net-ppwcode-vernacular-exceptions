=== Changes

* Added .NET 11 support while retaining .NET 8, .NET 9, and .NET 10 support.
* Updated the development SDK from `10.0.302` to `11.0.100`.
* Included .NET 11 in the GitHub Actions SDK setup for builds, tests, publishing, and build reproduction. Tests run for every target framework on Linux, macOS, and Windows.
* Refreshed NuGet lock files for all four target frameworks, preserving floating package version ranges.

=== Dependency changes

These changes affect test and build tooling; no consumer runtime dependencies were added or removed. Versions below compare the release with `1.2.1` and apply across all existing target frameworks. The new .NET 11 target uses the same versions.
